# Automate Church

Odoo 18 backend theme for parish databases, with an Orthodox look: burgundy and gold, a full-screen app drawer, and gilded app icons.

`18.0` is the release branch. There is no `main` branch. `odoo-saas-addons` pins this repository as the submodule `18.0/automatechurch`.

The installable module is `church_theme`.
